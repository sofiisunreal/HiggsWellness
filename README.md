# 🌿 Higgs Wellness

Higgs Wellness is a mobile wellness application developed in Android Studio, designed to help users build healthier habits and improve their overall well-being through personalized wellness strategies and AI-powered features.

---

## 🚀 Features

- 🔐 User authentication system
  - Sign Up
  - Sign In
- 🤖 AI-powered wellness assistance
- 🔊 Text-to-Speech (TTS) integration
- 🧘 Wellness strategy and guidance
- 📱 Clean and user-friendly mobile interface
- ⚡ Smooth Android app experience

---

## 🛠️ Tech Stack

- Kotlin
- Android Studio
- Firebase Authentication
- XML Layouts
- AI Text-to-Speech APIs

---

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/sofiisunreal/higgs-wellness.git
```

Open the project in Android Studio.

Sync Gradle dependencies and run the application on:

- 📱 Android Emulator
- 📲 Physical Android Device
